## 一、数据盘点

### 1.1 新增数据表

| 表名 | 行数 | 说明 |
|---|---|---|
| `mobile_day_flow_tag` | 56207 | 人口流动标签明细，按日+区域+标签维度拆分人数 |
| `pl_mobile_people_flow_data` | 202 | 人口活力汇总，按日统计进出总量、活力值、基线值 |

### 1.2 `mobile_day_flow_tag` 字段语义

| 字段 | 类型 | 说明 |
|---|---|---|
| `area` | VARCHAR(100) | 区域名称（淇澳岛、高新） |
| `tag` | VARCHAR(50) | 标签类别：年龄、性别、省内城市来源、省外城市来源、省外来源 |
| `label` | VARCHAR(100) | 标签值，如 `(31,35]`、`男`、`广州` |
| `type` | TINYINT | 1=总人数，2=进，3=出 |
| `label_cnt` | INT | 该标签下的人数 |
| `day` | DATE | 统计日期，范围 2024-06-02 ~ 2024-12-23 |

### 1.3 `pl_mobile_people_flow_data` 字段语义

| 字段 | 类型 | 说明 |
|---|---|---|
| `all_count` | INT | 总人流（含进出） |
| `in_count` | INT | 进人数 |
| `out_count` | INT | 出人数 |
| `statistics_date` | DATE | 统计日期 |
| `activation` | DECIMAL(10,2) | 活力值 |
| `base_line_value` | DECIMAL(10,2) | 基线值 |

### 1.4 与现有表的关系

| 已有表 | 新表 | 关系 |
|---|---|---|
| `population_flow_record` | `pl_mobile_people_flow_data` | 旧表由 AIDGP 同步，新表是移动端直供；字段口径需对齐 |
| `population_metric_daily` | `pl_mobile_people_flow_data` | 旧表按区域+网格聚合，新表是全域汇总 |
| — | `mobile_day_flow_tag` | **全新维度**，旧体系中无标签拆分能力 |

## 二、功能缺口与开发任务

按文档「人流问数」典型问法覆盖情况，逐项拆解。

### 任务 1：标签聚合预计算表

**目标**：为标签占比、TopN、趋势提供高效查询基础。

**建表**：

```sql
-- 人口流动标签日聚合表
CREATE TABLE IF NOT EXISTS population_tag_daily (
    id         BIGINT PRIMARY KEY AUTO_INCREMENT,
    day        DATE          NOT NULL,
    area       VARCHAR(100)  NOT NULL DEFAULT '',
    tag        VARCHAR(50)   NOT NULL,
    label      VARCHAR(100)  NOT NULL,
    type       TINYINT       NOT NULL DEFAULT 1,
    label_cnt  INT           NOT NULL DEFAULT 0,
    update_time INT          NOT NULL DEFAULT 0,
    UNIQUE KEY uk_pop_tag (day, area, tag, label, type),
    INDEX idx_pop_tag_day (day, tag, type),
    INDEX idx_pop_tag_area (area, day)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**刷新逻辑**：从 `mobile_day_flow_tag` 全量写入，启动时+按需触发。放入 `population.InitTables`。

---

### 任务 2：标签占比类快问

**典型问法**：
- "今天人流的年龄分布是怎样的"
- "进站人流中男女占比"
- "出站人流的来源地分布"

**快问路由**（新增 intent）：

| intent | kind | 图表类型 | 说明 |
|---|---|---|---|
| `population.tag.distribution` | `pie` | 饼图 | 单标签+type 的 label 占比分布 |

**查询逻辑**：

```sql
SELECT label, label_cnt
FROM population_tag_daily
WHERE day = ? AND area = ? AND tag = ? AND type = ?
ORDER BY label_cnt DESC
```

**返回结构**：
```json
{
  "tag": "年龄",
  "type": 2,
  "items": [
    {"label": "(31,35]", "count": 7567, "pct": 18.3},
    {"label": "(36,40]", "count": 7693, "pct": 18.6}
  ]
}
```

---

### 任务 3：标签 TopN 类快问

**典型问法**：
- "进站人流来源地排名前5"
- "今天出站最多的是哪个年龄段"

**快问路由**：

| intent | kind | 图表类型 |
|---|---|---|
| `population.tag.topn` | `bar_rank` | 水平柱状图 |

**查询逻辑**：同占比查询，取 `LIMIT N`，排名序号作为 name。

---

### 任务 4：标签趋势类快问

**典型问法**：
- "最近一周年轻人群（19-30岁）的进站趋势"
- "过去一个月女性人流变化"

**快问路由**：

| intent | kind | 图表类型 |
|---|---|---|
| `population.tag.trend` | `line_trend` | 折线图 |

**查询逻辑**：

```sql
SELECT day, SUM(label_cnt) AS cnt
FROM population_tag_daily
WHERE day >= ? AND day <= ? AND tag = ? AND label IN (?,?)
  AND type = ? AND area = ?
GROUP BY day ORDER BY day
```

**参数提取**：需要从问题中提取 `tag`、`label` 列表（可多个年龄段合并）、`type`。

---

### 任务 7：参数提取引擎扩展

在 `fast_path_params.go` 的 `ExtractedParams` 中新增字段：

```go
Tag      string   // 年龄/性别/省内城市来源/省外城市来源/省外来源
Labels   []string // 具体标签值，如 ["(31,35]","(36,40]"]
PopType  int      // 1=总, 2=进, 3=出; 默认0表示不区分
TopN     int      // 排名数，默认5
Area     string   // 区域
```

**关键词映射表**：

| 关键词 | tag | type |
|---|---|---|
| 年龄/岁/年龄段 | 年龄 | 默认1 |
| 进站/进入/入 | — | 2 |
| 出站/离开/出 | — | 3 |
| 男/男性 | 性别 | 默认1 |
| 女/女性 | 性别 | 默认1 |
| 来源/来自 | 省外来源/省外城市来源 | 默认1 |
| 活力/活跃 | — | activation |
| 年轻人/青年 | 年龄 | 1, labels=[(19,22],(23,25],(26,30]] |
| 中年 | 年龄 | 1, labels=[(36,40],(41,45],(46,50]] |

## 四、验收标准

针对文档中「人流问数」各类典型问法，逐条可问、可答、有图表：

| 问法类别 | 验收问题示例 | 期望输出 |
|---|---|---|
| 单指标数值 | "今天总人流多少" | 数值卡片 |
| 占比/比例 | "进站人流的年龄分布" | 饼图+占比文字 |
| 排名/TopN | "来源地排名前5" | 水平柱状图 |
| 均值/时段 | "今天按小时人流趋势" | 折线图（已有） |
| 多维度对比 | "高新和淇澳岛人流对比" | 分组柱状图（已有） |
| 趋势/变化 | "最近一周年轻人进站趋势" | 折线图 |
| 组合趋势 | "男女进出趋势对比" | 双折线图 |
| 综合分析 | "今天人流综合分析" | 总量+活力+饼图+排名 |
| 模糊提问 | "哪里人最多" | 澄清或默认区域排名 |
| 异常识别 | "最近人流有异常吗" | 活力偏离+流动人口异常 |
